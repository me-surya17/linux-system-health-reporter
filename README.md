# Linux System Health Reporter

## About
A Bash project that collects basic Linux system information.

## Features
- Hostname
- Kernel version
- Disk usage
- Memory usage
- Top running processes

## How to Run

Make the script executable:

    chmod +x system_report.sh

Run the script:

    ./system_report.sh

View the report:

    cat system-report.txt

## Project Files
- system_report.sh: Bash script
- system-report.txt: Generated report
- README.md: Project documentation
